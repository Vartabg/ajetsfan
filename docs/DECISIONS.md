# Release decisions

## 2026-10-20 — truthful coverage and stable daily play

Player archive charts retain their verified per-game source rather than inventing rows from independent aggregate totals. Each archive section exposes its cutoff and successful check; differing current totals receive an explicit explanation. The normal daily archive publication reconciles newer games.

Daily puzzles use a compact, server-only immutable series. New versions must have a future effective date and preserve earlier versions, so a runtime publication cannot silently change an answer. The daily-progress key changes once for this migration; the historical tally remains.

Next Gen refresh and runtime/compiled selection work per season. A source gap keeps the original verified season and its check time; valid independent seasons can advance. Later failed attempts remain visible, and a verified recovery clears the warning. Overall retained health is not hidden.

Inline player code ships with its already-interactive control. External publisher SDKs and players still load only after the reader presses play. Home media features require a Jets/NYJ headline; mixed-sports coverage remains available in the Media Room.
