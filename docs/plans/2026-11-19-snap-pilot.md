## Fan comparison

Give five Jets fans the same task on their own phone. Ask them to find who intercepted Cleveland’s last pass in the 2022 comeback and share a link that lets a friend verify it. Start from each site’s home page. Alternate which site each person uses first and keep the task wording identical. Record the time until the link is shared, whether it opens directly on the correct play, and whether the recipient can identify the defender and game clock from it. Ask which site they would use next Sunday and why. Report each result and the median times. This pilot includes automated checks of the journey. Participant results are pending.

## Pilot evidence

The shipping fixture contains 77,277 plays from 458 published games. The 28 compressed season files total 2,857,975 bytes. A full rebuild from the same nflverse files produced byte-identical results. For the 1999–2025 sample, 428 games have a qualifying run or pass with a model estimate. The 1%, 5% and 10% cutoffs return 1–134, 2–179 and 5–194 in wins and losses. The default pre-touchdown comparison for Wilson returns six wins and 27 losses from games before September 18, 2022.

The pilot browser checks exercise a shared play and the actual HTML, navigation payload, social image, clock picker, clipboard, Back, reload and filters. The real ESPN event links for Kincaid and Davis resolve to archived evidence. ESPN’s combined Wilson row preserves its provider identity. The current scheduled Chargers game opens at a waiting screen. Phone and desktop checks cover keyboard operation, overflow and accessible controls.
